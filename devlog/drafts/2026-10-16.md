# 2026-10-16 (draft)

Decision: English only in v1.0 over code-switched speech (ADR 0010).
Why: the fixture set goes from 24 to 23 files. The Telugu-English clip (mixed_lang.mp4, 39,354 bytes) and the MIXED_LANG warning code go with it, along with the code-switched eval suite.
Cost: non-English footage is transcribed on a best-effort basis and nothing non-English is measured. One differentiator from the original plan is gone.
Revisit if: a user needs non-English eval numbers. ADR: docs/adr/0010-english-only.md

Broke: `tapesift doctor` reported CUDA as null on a real L4.
Cause: driver 610 prints "CUDA UMD Version: 13.3", not "CUDA Version:". The mocked tests passed because the mocks returned the text we expected.
Fix: the parser accepts both forms (src/tapesift/cli/doctor.py), and the real 610 banner is a regression test (tests/unit/test_doctor.py).
Lesson: a mock only knows the output we thought the tool prints. One run on real hardware found what 30 unit tests did not.

Shipped: `tapesift doctor` (P0.7). It reports Python, FFmpeg, CUDA, GPUs, NVDEC and free disk, picks a cpu, gpu or server profile, and lists every network call tapesift can make. The probes are injected, so the unit tests need no GPU. Verified on one Modal L4; the output is in docs/verification/doctor-L4.json.
