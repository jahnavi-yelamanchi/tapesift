- **PR #34 merged (#21).** Probe and decode now open every media file through one checked file descriptor. Nine containers are allowed. FIFOs and devices are refused at once.
  - 521 tests on main (70 new). Each new test uses real attack files built at test time.
  - The test-auditor ran 19 injected bugs. 16 were caught. The 3 misses are equivalent code, not missed bugs.
  - Two limits, stated in the PR. The protocol lock is a backup layer; no behavioural test shows it doing extra work. The 30 s timeout covers only reads that keep returning. A read stuck in the kernel (a dead network mount) still hangs. That is #36.

- **Two follow-ups.** #35: decode warnings leak the full file path (older issue; not caused by #34). #36: the runner needs a wall-clock limit per file that kills a stuck worker.
- **M1 spec (#25).** The critic found 14 problems. The main ones: CI would pull 6 GB of CUDA torch into every job (fixed: CPU-only torch for dev and CI); captions turned off silently (fixed: a warning and a `doctor` line); one bad word timestamp failed a whole file (fixed: clamp at the stage boundary); a 3-hour file needed about 690 MB of RAM for transcription (fixed: chunked audio with a memory test); two dependencies need macOS 14+ on Apple Silicon (a platform-floor card). The planner pushed back on one finding with evidence (ASR keeps a chunk list, not a stream).
- **Council on the T3 cards.** Two seats (opus and sonnet) argued each card, then one rebuttal round.
  - First round: the two seats agreed on 5 of 7 cards. They split on the config resolution rule (card 4) and on the LGPL dependency (card 7).

  - Every card, the agent picks, and the final pick are in [the scorecard](../../docs/decisions-scorecard.md). "My pick" is blank for the owner (#16).
- **Platform floor (card 10).** Linux x86_64 with glibc 2.28+, and Apple Silicon on macOS 14+. No Intel Macs.
